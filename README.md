# Alejo Analista - Landing Page

Landing del canal de Telegram [Alejo Analista](https://t.me/alejoanalista10): pronósticos diarios de tenis de mesa, gratis.

## Estructura

```
.
├── index.html
├── css/styles.css
├── js/main.js
└── assets/
    ├── logo/    <- sube aquí tu logo
    └── picks/   <- sube aquí las capturas de picks acertados
```

## Logo
Sube cualquier imagen a `assets/logo/`. Se muestra sola en la barra y el hero.

## Picks
Sube capturas a `assets/picks/`. Aparecen solas en la sección Picks, con zoom al tocar. Nombra con fecha (`2026-09-30_01.jpg`).

## Publicar
Settings > Pages > Source: `main` / root.

## Paleta
Negro `#05070d`, azul `#0055ff`, blanco `#f5f5f5`, gris `#a6adbb`.
