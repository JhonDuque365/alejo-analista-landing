# Logo

Sube aquí tu logo (PNG, SVG, WEBP o JPG, con el nombre que quieras, por ejemplo `logo.png`).

Se mostrará automáticamente en la barra superior y en el encabezado de la landing, reemplazando la corona provisional.

Recomendado: fondo transparente, mínimo 512 px de ancho. Si hay varios archivos, se usa el primero por orden alfabético.
