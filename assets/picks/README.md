# Picks acertados

Sube aquí las capturas de tus pronósticos acertados (PNG, JPG, WEBP).

Aparecerán automáticamente en la sección Picks, de la más reciente a la más antigua según el nombre del archivo.

Nombra los archivos con la fecha para mantener el orden:
- `2026-09-30_01.jpg`
- `2026-09-30_02.jpg`

Usa solo capturas reales y verificables. Tras subir, GitHub Pages tarda 1-2 minutos en actualizar.
